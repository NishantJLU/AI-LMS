# Contributing to AI-LMS

Thank you for your interest in contributing to AI-LMS! We welcome contributions from everyone.

## How to Contribute

1. **Fork the Repository**: Create your own fork of the project.
2. **Clone the Repo**: Clone your fork to your local machine.
3. **Create a Branch**: Create a new branch for your feature or bug fix.
4. **Make Changes**: Implement your changes and ensure the code follows the project style.
5. **Commit Changes**: Use clear and descriptive commit messages.
6. **Push Changes**: Push your branch to your fork on GitHub.
7. **Submit a Pull Request**: Open a PR against the main repository.

## Development Setup

See the [README.md](./README.md) for instructions on setting up the local development environment.

## Code of Conduct

Please be respectful and professional in all your interactions with the community.
